## 📊 Actuarial projects

| Project | What it does |
|---|---|
| [**claims-reserving**](https://github.com/Razzouknoreddine/claims-reserving) | Chain-ladder, Mack and Bornhuetter-Ferguson reserving implemented from scratch; reproduces Mack (1993) exactly and backtests on real CAS Schedule P data |
| [**bav-pension-valuation**](https://github.com/Razzouknoreddine/bav-pension-valuation) | Pension liability valuation with the entry age normal method (§ 6a EStG) and Projected Unit Credit (HGB / IFRS), using Destatis cohort life tables and Bundesbank discount rates; interest-rate sensitivity, duration and longevity risk |
| [**mc-sde-finance**](https://github.com/Razzouknoreddine/mc-sde-finance) | Monte Carlo simulation of interest-rate and asset models (Vasicek, CIR, Heston, Merton) with Euler-Maruyama and Milstein schemes; Value-at-Risk, Expected Shortfall and Kupiec backtesting |

Every project is tested automatically with GitHub Actions and validated against analytical or published results.
